# Codex 开发与办公提速

**减少重复读取、反复检查和无效返工，让 Codex 达到要求后及时交付。**

改一个按钮文案，却等它重新检查整个项目；调整报告中的一段话，却看到它又从头读了一遍所有资料；表格已经核对过，还在一轮轮“再确认”。

如果你遇到的是这类慢，这个 Skill 就是为你准备的。它给 Codex 一套更精简的执行规则：**复用已有材料和有效检查，只处理当前任务，需要验证时检查相关部分，完成后结束。**

适合用 Codex 开发应用、修改文档、整理报告和处理表格的人。安装名称为 `convergent-code-review`。

## 它能帮你省掉什么

| 你遇到的情况 | 使用后，Codex 应该怎样处理 |
| --- | --- |
| 一个小改动触发整套规划、开发、审核流程 | 按任务影响选择最小执行方式，简单任务由当前 Agent 直接处理 |
| 相同资料或文件被反复完整读取 | 复用已经掌握且仍有效的内容，有变化或缺口时才补读相关部分 |
| 改完局部，又重新检查整个项目或文档 | 检查修改部分及其影响范围，必要时才扩大 |
| 同一个问题换种说法又被提出来 | 沿用已有结论，有新证据才重新打开 |
| 为了“更完美”不断改写、重构 | 优先满足你的要求，可选优化单独列出 |
| 明明已完成，还不断追加检查 | 满足交付条件后结束，不默认进入下一轮 |

你可以在任务开始时使用，也可以在 Codex 已经陷入重复工作时使用。

## 1. 安装

在终端运行（需要 Node.js / npm）：

```bash
npx skills add lulu233camellia/convergent-code-review --skill convergent-code-review -g -a codex
```

这会为 Codex 安装该 Skill。安装后打开新会话，在任务前加上 `$convergent-code-review`。

如果你习惯让 Codex 操作，也可以把下面这句话发给它：

```text
请从 https://github.com/lulu233camellia/convergent-code-review 安装 convergent-code-review Skill，供我的 Codex 使用。
```

## 2. 直接这样用

### 开发：小改动快点交付

```text
使用 $convergent-code-review 完成这个修改：把提交按钮改成保存按钮。
只检查受影响的行为，复用仍有效的测试结果，满足要求后直接交付。
```

### 办公：修改文档或报告

```text
使用 $convergent-code-review 修改这份周报中的“本周进展”。
沿用已有材料，只改我指定的内容，核对相关事实和上下文后交付。
```

### 表格：更新数据并核对结果

```text
使用 $convergent-code-review 更新这张表的本月数据。
核对来源、公式和受影响的汇总结果，已经有效检查过的部分直接复用。
```

### Codex 已经反复检查时

```text
使用 $convergent-code-review 收束当前任务。
先沿用已经完成的工作和检查结论，只处理剩余阻断问题。
如果已经满足我的要求，就交付结果并结束。
```

不需要单独建立一个“快速变更 Agent”，也不需要记住审核术语。**说明要完成什么，再加上 Skill 名称即可。**

## 哪些任务更适合

- **开发迭代**：修改界面、修复范围明确的问题、复核已有修复。
- **文档与报告**：局部修改、资料整理、按既定结构补充内容。
- **表格工作**：更新数据、调整公式、核对受影响的统计结果。
- **正在卡住的任务**：材料已经够了、结果基本完成，但 Codex 仍在重复检查或扩展任务。

复杂任务仍需完成相应验证。例如改一个数字可能影响整张汇总表，修改权限逻辑也可能影响多个模块。Skill 会根据实际影响确定检查范围。

## 它如何加快任务

提速来自减少任务中不必要的步骤：优先使用已有上下文、复用有效证据、缩小复查范围、避免重复问题、明确结束条件。

**一次检查已经足够，就在这一轮结束。** 只有新改动、新证据或具体风险才继续；默认最多三轮实质复核，仍有阻断问题时说明原因和下一步。

如果等待来自模型生成、网络、外部服务或必要的大型计算，耗时仍取决于这些环节。实际能节省多少时间取决于原任务中的重复工作比例，目前没有统一提速倍数的实测承诺。

## 常见问题

**必须每次写 Skill 名称吗？** 直接写 `$convergent-code-review` 最明确。宿主也可能根据任务自动选择；是否加载以当前会话为准。

**会把必要检查省掉吗？** 它要求检查与任务影响匹配。事实核对、受影响公式、相关测试，以及项目明确要求的检查仍需完成。

**能和其他 Skill 一起用吗？** 可以。其他 Skill 负责具体工作，这个 Skill 约束重复读取、复核和返工；双方共用已有结论与审核次数。

**可以用于 Claude Code 等工具吗？** 可以用于支持 Agent Skills 的工具，安装目录和可用操作取决于宿主。上面的命令针对 Codex。

## 原理与来源

方法起点是 [Claude Code 团队的审核实践](https://claude.dev/blog/solving-code-review-at-anthropic/)，本项目将其中减少重复审核、核验证据和明确结束条件的思路转成可执行规则，并自行扩展到文档与表格任务。
