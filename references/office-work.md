# 文档、报告与表格任务

在办公产物的制作、编辑或核对中使用。继续用户原本要求的工作；事实来源、排版或编辑方式遵循对应文档工具、专业 Skill 和用户约定。

## 复用当前材料

先利用已经取得的原文、数据、来源、结构和已确认要求，识别尚未完成的部分。不要让用户重述已有决定，也不要因为进入此 Skill 就重新收集所有材料。

需要补读时，优先读取本次涉及的段落、工作表、公式及其上下文。以下情况应更新相应内容：

- 来源、文件或在线文档已变化，旧摘录不能代表当前版本。
- 修改会影响引用、章节结论、公式依赖或汇总结果。
- 现有上下文不足以确认事实或防止覆盖其他修改。

没有版本信息时，不猜测在线文档仍与旧缓存一致。按所用工具的要求取得当前状态后再写入；这属于防止覆盖的必要读取。

## 按任务完成一次有效检查

| 任务 | 检查内容 | 何时扩大范围 |
| --- | --- | --- |
| 局部文档修改 | 指定内容是否完成，相关事实、术语和上下文是否一致 | 修改影响其他章节、交叉引用或整体结论 |
| 报告或资料整理 | 结论能否追到已有来源，关键数字、日期、口径是否一致 | 新材料改变关键结论，或原来源不足以支持要求 |
| 表格更新 | 修改区域的数据来源、类型、单位和公式，以及相关汇总与图表 | 依赖关系传播到其他工作表、引用、筛选或统计范围 |
| 格式调整 | 用户指定的版式是否落实，是否引入内容丢失或显示问题 | 模板、分页或共享样式影响多个区域 |

首次检查应覆盖本次请求范围。修复后只复核修复内容及其影响部分；已核对且输入未变的内容继续有效。用户要求通篇校对或全表核算时，必须覆盖其完整要求。

不得把没有查证的事实、没有重新计算的公式或没有查看的排版记为已验证。工具无法完成必要核验时，说明具体缺口及影响，不反复做无法回答该问题的替代检查。

## 避免无效返工

同一错误保持同一结论；修复且核实后，没有新材料或新证据就不重新提出。措辞偏好和结构调整只有在影响用户要求时才继续处理，不让可选润色无限扩展。

若内容仍有阻断问题，修复后做针对性复核。与主 Skill 共用同一工作项和最多三轮实质复核的默认预算，不另设“事实审核、格式审核、最终审核”各自循环。一次有效检查通过即可交付。

最终给出产物位置、完成的修改，以及会影响使用的未解决事项即可。小任务不强制创建问题台账、技术状态码或验证报告。

修改在线文档、发送报告、覆盖文件等动作仍按当前授权执行；遵守用户要求的批注、修订或格式标记。不能为减少步骤而越过实际操作边界。
