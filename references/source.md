# 来源与适配边界

原文：[How the Claude Code team does code review](https://claude.dev/blog/solving-code-review-at-anthropic/)。作者：Addy Osmani、Morgan Westlee Lunt、Qing Wang。发布：2026-10-15；核对：2026-11-06。

文章提供的方向是：用分层验证和按风险分配投入保障质量；核实发现并减少噪声；限制返工轮次、缩小后续复审范围、避免重复发现；保留必要人工责任，并通过可恢复的交付和实际结果持续改进审核。

## 本 Skill 自行定义的执行规则

- 首次覆盖本次完整变更，之后默认按问题和修复影响面复核。原文是在前几轮后缩小范围；这里采用更早的默认切换，但仍允许有证据地扩大范围。
- 默认三轮实质审核上限、共享工作项计数、稳定问题 ID、四种结论和工具失败重试上限，是便于 Agent 执行的具体约定，不是原文的实现代码。
- 按现有授权与工具能力安排独立核验，不复刻托管服务的多 Agent 投票架构；没有独立证据时明确其缺口。
- 人工批准人数、作者信任规则、CI 和发布策略以目标项目为准，不照搬作者团队的组织政策。
